# Festival Budaya Kupang 2027

Situs profil simulasi untuk tugas UTS Pemrograman Web — Universitas Citra Bangsa.
Seluruh isi (jadwal, angka, testimoni, kontak) adalah data contoh.

## Isi proyek
- `index.html` — halaman utama (Beranda, Tentang, Program, Galeri, Amarasi Barat, Hubungi)
- `style.css` — tampilan responsif, menu hamburger di layar ponsel
- `script.js` — menu hamburger dan validasi formulir contoh
- `assets/images/` — taruh 16 gambar di sini (lihat `DAFTAR-GAMBAR.txt`)

## Cara membuka
Klik dua kali `index.html`. Tidak perlu server. Gambar harus sudah ada di `assets/images/`.
